# Pièces Auto Châteauguay

Site web une page, bilingue (français / anglais), pour Pièces d'autos Châteauguay inc. —
succursales de Châteauguay, Sainte-Martine et Saint-Rémi.

## Structure

| Fichier | Rôle |
|---|---|
| `index.html` | Le site complet — HTML, CSS et JavaScript dans un seul fichier |
| `assets/` | Logo, photos des succursales, image d'entête et les 6 catalogues PDF |

## Modifier le contenu

Tout le contenu modifiable se trouve dans trois blocs commentés près du bas de `index.html` :

- **`BRANCHES`** — adresses, téléphones et heures d'ouverture des trois succursales
- **`DOCS`** — la liste des catalogues et brochures
- **`T`** — toutes les traductions françaises et anglaises

Aucune étape de compilation : ouvrez `index.html` dans un navigateur pour prévisualiser.

## Hébergement

Site statique. Fonctionne sur GitHub Pages, Netlify, ou tout hébergeur web classique.
